# พรานปลา (PranPla)

แอปตกปลา + เอาชีวิตรอด แบบเว็บแอป (PWA) ติดตั้งลงมือถือได้ ไม่ต้องมี API key ไม่มีโฆษณา ข้อมูลเก็บในเครื่อง

## ทำอะไรได้
- **แผนที่** 3 แบบ: แผนที่ถนน (โทนมืด) / ดาวเทียม / ภูมิประเทศ, ตำแหน่ง GPS + ทิศที่หันหน้า
- **ปักหมุด** กดค้างบนแผนที่ หรือปุ่ม ＋ : จุดตกปลา ที่จอดรถ แคมป์ จุดอันตราย ฯลฯ ใส่โน้ต/รูปได้
- **หาแหล่งน้ำ** ปุ่ม 💧 ดึงหนอง บึง อ่าง แม่น้ำ บ่อตกปลา รอบแผนที่จาก OpenStreetMap
- **พยากรณ์** อากาศ 14 วัน + คะแนนปลากิน 0–100 รายชั่วโมง, ช่วงเวลาดีที่สุด, ช่วงดวงจันทร์ (solunar), ฤดูกาลและปลาน่าตก
- **เอาชีวิตรอด** เข็มทิศนำทางไปหมุด, พิกัด, ส่งตำแหน่งขอความช่วยเหลือ, เวลาแสงที่เหลือ, ไฟฉาย, SOS, นกหวีด, เบอร์ฉุกเฉิน, เช็กลิสต์
- **บันทึกเส้นทางเดิน** 👣 แล้วนำทางกลับจุดเริ่ม
- **สมุดบันทึกปลา** ชนิด ขนาด เหยื่อ รูป พร้อมอากาศและข้างขึ้นข้างแรมตอนนั้น, ส่งออก/นำเข้าไฟล์สำรอง
- **ออฟไลน์** ตัวแอปเปิดได้ไม่มีเน็ต แผนที่บริเวณที่เคยเลื่อนดูไว้จะถูกเก็บไว้ใช้ต่อ

## วิธีลงมือถือ (GitHub Pages)
1. สร้าง repo ใหม่ใน GitHub เช่น `pranpla` (Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (Add file → Upload files)
3. Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `(root)` → Save
4. รอ 1–2 นาที เปิด `https://<ชื่อผู้ใช้>.github.io/pranpla/` ด้วย Chrome บนมือถือ
5. อนุญาต "ตำแหน่ง" แล้วกดเมนู ⋮ → **เพิ่มไปยังหน้าจอหลัก / ติดตั้งแอป**

ต้องเปิดผ่าน https เท่านั้น GPS, ไฟฉาย และโหมดออฟไลน์จึงจะทำงาน (GitHub Pages เป็น https อยู่แล้ว)

## ไฟล์
- `index.html` `style.css` `app.js` – ตัวแอป
- `data.js` – ชนิดหมุด รายชื่อปลา/เหยื่อ ฤดูกาล เช็กลิสต์ (แก้เองได้ง่าย)
- `sw.js` – ออฟไลน์ + แคชแผนที่ (แก้โค้ดแล้วเปลี่ยน `pranpla-v1` เป็น v2 เพื่อบังคับอัปเดต)
- `lib/` – Leaflet, SunCalc
